# Fluxos Cadê — pasta de trabalho dos sócios

Aqui moram as **jornadas da plataforma Cadê**, um documento por usuário. O objetivo é **completar todas as jornadas** (as que já existem e as que existirão) para entregar ao João a regra de negócio pronta.

## Como usar

- Cada arquivo é uma jornada de um ator. Dentro, cada sub-jornada tem um **status** e ou já vem **preenchida** (com o que vocês escreveram no `UX CADE.txt`) ou tem um **placeholder** dizendo o que precisa ser escrito + as perguntas a decidir.
- **Editem direto nos arquivos.** É material de trabalho, não é definitivo.
- Ao escrever/refinar um trecho, troquem o status para ✅ e marquem cada item como **[MVP]** (entra até 01/08) ou **[Fase 2]**.

## Legenda de status

- ✅ **Escrito** — já temos a jornada descrita (esboço dos sócios; pode precisar de refino/validação com o código).
- ✍️ **A escrever** — existe no sistema, mas falta a regra de negócio escrita.
- 🆕 **Novo** — ator/fluxo novo, sem esboço e sem estar completo no código.
